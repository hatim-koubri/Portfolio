## Screenshot Recommendations

- Use PNG format.
- Recommended cover image size: `1600x900`.
- Recommended screenshot size: `1440x900` or `1600x900`.
- Keep screenshots clean, without browser bookmarks.
- Prefer real application screens over logos.
- For diagrams, export as PNG with readable text.
- If the image does not appear, restart the dev server and check the exact filename.
